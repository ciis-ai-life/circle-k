# Circle‑K — Control de Cíclicos y Caducidades

Sistema web para el control de inventario, productos cíclicos y seguimiento de fechas de caducidad en tienda de conveniencia Circle‑K.

## Funciones
- 📋 Registro y consulta de productos
- 📅 Alerta de caducidades próximas a vencer
- 🔄 Gestión de productos de rotación cíclica
- 📱 Diseño adaptable para celular y escritorio
- 💾 Funcionamiento con soporte offline (Service Worker)

## Acceso
👉 Página en línea: https://ciis-ai-life.github.io/circle-k/

## Archivos principales
- `index.html` — Página principal y aplicación
- `sw.js` — Soporte para funcionamiento sin conexión
